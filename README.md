# Ad Surreal (`ad-surreal-skill`)

> **Universal Direct Image Generation Engine (通用直接生图引擎)**  
> 拒绝纯提示词输出，输入任何需求直接渲染高质量大片并内联展示。

---

## 🌟 核心原则：直接生图，拒绝提示词堆砌

本技能是一个真正**开箱即用的直接生图引擎**：
- **直出图像**：接收用户输入后，内部自动强化视觉语言、光学与材质，直接调用生图模型渲染图片并以 Markdown 绝对路径在对话中展示：`![alt](/path/to/image.jpg)`。
- **全品类通用**：
  - **商业广告与主视觉 (Commercial KV)**：超现实隐喻、尺度错位、物性反转、留白工程。
  - **高端商业人像 (Portraits & Fashion)**：真实微孔皮肤（次表面散射 SSS）、克制高级神态、双色轮廓光。
  - **概念艺术、风景、建筑与产品**：工业级渲染、哈苏镜头质感、微米级真实细节。
- **零繁琐提示词倾倒**：专注呈现最终视觉成果，仅附带极简标题与概念说明。

---

## 📁 核心脚本

- `scripts/generate_image.py`：通用直接生图脚本，直连图像生成服务，自动解码并保存高分辨率图像。
- `scripts/generate_ad_image.py`：商业海报与资产管理脚本。
- `scripts/validate_skill.py`：技能语法与完整性校验脚本。
